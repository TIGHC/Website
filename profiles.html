Game profiles

Profiles v1.3.0 Engine v3.8.0

Every profile below ships in TIGHC Profiles, downloaded automatically on first launch. Each one maps a game's default keybinds to vibration intensity ranges — pressing a key fires the vibration, holding sustains it, releasing stops it. TIGHC auto-selects the matching profile from the focused window's title.

Don't see your game?

Copy an existing profile folder (minecraft/ is the most complete example), rename it, and edit window_titles plus bindings to match — or use the GUI's Profiles → New profile... button to do it interactively. Details in the TIGHC Profiles README. Want to share it back? Open a PR against TIGHC Profiles.
